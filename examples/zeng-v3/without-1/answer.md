# 判断

**不覆盖。** 这篇论文的势能与反应模拟针对高温、高密度的纯甲烷–氧气体系；约 1 atm、低于 2000 K、燃料经惰性气体稀释的实验室甲烷–空气火焰污染物路径，不在其已训练和已演示的条件之内。

# 后续工作所要求的条件

用论文给出的势能，预测实验室甲烷–空气火焰中的污染物路径，工况约为：

- 压力约 1 atm
- 温度低于 2000 K
- 燃料用惰性气体稀释
- 氧化剂为空气（含氮气）

# 论文实际给出的方法与条件

势能是在 MN15/6-31G** 参考数据上训练的 DeepPot-SE 神经网络势能（DeePMD）。参考结构来自 3000 K 下的 ReaxFF 采样，以及随后的主动学习短程分子动力学；化学组成围绕甲烷燃烧中的碳、氢、氧。

用该势能做的反应分子动力学为：

- 周期性盒子，100 个 CH4 与 200 个 O2，共 900 个原子
- 密度 0.25 g/cm³
- NVT，Berendsen 恒温，温度保持在 3000 K，时间步长 0.1 fs，轨迹长 1 ns
- 另有同组成、同密度的 NVE 能量守恒检验

作者写明选择较高密度（因而较高压力）和较高温度，是为了在远短于实验的模拟时间内提高碰撞与采样效率。按文中组成、密度与 3000 K，用理想气体估算压力约为 2.3×10³ atm，比 1 atm 高三个数量级。文中未报告 1 atm 或低于 2000 K 的模拟。

作者还写明：实验通常不烧纯燃料，而是把燃料混入相对惰性的气体；把神经网络势能与增强采样结合起来、使模拟条件更接近真实实验，属于未来工作。

轨迹中记录了 505 种物种和 798 个反应，其中 32 条主路径与实验甲烷氧化网络一致，130 条出现在 GRI-Mech 中，物种包括甲醛、甲酰基、CO、CO2 和 H2O。部分实验上已知的反应在轨迹中没有出现，作者将其主要归因于模拟温度偏高。从单条轨迹估计的速率常数，作者认为还不够准确，不宜直接用于动力学建模。电子激发态、以及含氮物种，均未进入这套势能。

# 与目标工况的对应

| 目标 | 论文中的对应事实 |
| --- | --- |
| 约 1 atm | 生产模拟密度为 0.25 g/cm³，作者称为高密度、高压；同温下约为数千大气压 |
| 低于 2000 K | 训练集采样与生产轨迹均为 3000 K；作者把缺失反应和个别新物种与这一高温联系起来 |
| 惰性气体稀释 | 盒子只有 CH4 与 O2；惰性稀释被明确写成未来工作 |
| 甲烷–空气火焰 | 势能与轨迹只含 C/H/O；空气中的 N2 以及依赖氮气的污染物通道不在训练化学空间内 |
| 污染物路径的定量预测 | 轨迹给出的是该极端条件下的反应事件与粗略速率；作者写明这些速率不宜直接进入动力学模型 |

甲醛、CO 等碳氢氧化中间体在论文的主反应网中确实出现，但这是 3000 K、高密度纯氧燃烧轨迹里的物种，不能代替上述实验室火焰工况下的污染物路径。

# 结论

论文的神经网络势能及其验证，覆盖的是 3000 K、0.25 g/cm³、CH4/O2 的甲烷氧化反应网。实验室甲烷–空气火焰在约 1 atm、低于 2000 K、惰性气体稀释下的污染物路径，在压力、温度、稀释气体和空气氮气四个方面都落在这一覆盖范围之外。
