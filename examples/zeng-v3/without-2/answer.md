# 判断

**不覆盖。** 不能用这篇论文的势能去预测实验室甲烷–空气火焰在约 1 atm、低于 2000 K、燃料经惰性气体稀释条件下的污染物路径。

# 依据（仅据 paper.pdf）

论文训练并使用的是 DeepPot-SE / DeePMD 神经网络势能，参考数据为甲烷燃烧构型在 MN15/6-31G** 下的能量与原子力。应用对象是纯甲烷–氧气的反应分子动力学，不是实验室甲烷–空气火焰。

条件与目标工况逐项不符：

1. **温度。** 生产轨迹在 NVT 系综、Berendsen 热浴下保持在 **3000 K**。ReaxFF 初始采样同样设为 3000 K。论文写明选取较高温度是为了提高碰撞概率和采样效率，并指出部分实验已观察到的反应在模拟中未出现，**最可能是因为模拟温度偏高**。文中没有低于 2000 K 的采样、训练或验证。

2. **压力 / 密度。** 模拟盒子为 100 个 CH₄ 与 200 个 O₂（共 900 个原子），密度 **0.25 g/cm³**。论文明确称这是**较高密度，因而也是较高压力**，目的同样是提高碰撞概率。该设定不是约 1 atm 的实验室火焰。

3. **组成与稀释。** 体系只有 CH₄ 与 O₂，参考数据来自 CH₄/H₂ 的 ReaxFF 采样及随后的 C/H/O 主动学习，力场为 CHO-2008。没有 N₂、空气，也没有惰性稀释剂。论文直接写明：实验通常不烧纯燃料，而是把燃料混入相对惰性的气体；**把模拟条件做得更接近真实，属于今后把该势能与增强采样结合的工作**。因此惰性气体稀释不在本文覆盖范围内。

4. **污染物路径所需要的化学空间。** 轨迹分析的是甲烷氧化网络（甲醛、甲酰、CO、CO₂ 等），检出 505 种物种、798 个反应，其中 130 个见于 GRI-Mech。物种与反应都来自上述纯 CH₄/O₂、3000 K、高密度轨迹。势能的元素与构型空间不含氮，不能描述空气火焰中依赖 N₂ 的污染物通道；第三体与稀释效应也没有对应的训练环境。论文还写明，由单条轨迹抽出的速率常数**还不够准确，不能直接用于动力学建模**。电子激发态也明确留待以后。

# 结论

方法是针对高密度、3000 K、未稀释 CH₄/O₂ 的神经网络势能与反应分子动力学。论文自己把惰性气体稀释和更接近实验的条件列为未完成的后续工作。该势能的方法与条件都不覆盖约 1 atm、低于 2000 K、惰性气体稀释的实验室甲烷–空气火焰污染物路径。
