# 方法适用性核对

版本 `method-fit-check-v1`。一次调用只处理一篇已在工作目录中的全文，外加一个写明的后续工作。

## 何时使用

读者要判断：这篇论文的方法、模拟或实验条件，是否覆盖自己准备做的下一步。典型下一步是换一个温度、密度、分子或现象（冲击、热分解、实验室火焰）。

不要用于：没有全文、只有摘要、付费墙 PDF 的再分发、或让你重跑论文里的模拟。

## 许可

只阅读工作目录里的文件。PDF 上能看到的许可证原文照录，并标明页码。看不到许可证就写“本文未显示许可证”，不要猜测。不要下载付费墙全文，不要把 CC BY-NC-ND 文件改写成衍生件。引用用短句加页码，不把全文贴进答案。

## 输入

- 工作目录中的一篇 PDF 或与其对应的文本。
- 一句后续工作：谁想做什么、在什么条件。

## 输出

只写 `answer.md`。使用下面的标题，不要增删：

1. `文献身份`：题名、年份、DOI（文中有才写）、许可证原文或“本文未显示许可证”。每项附页码。
2. `方法与条件`：模型类别、训练数据来自什么（DFT、经验力场或实验）、粗粒化或反应性、系综、温度、压力或密度、时长、体系大小。每行：条目、原文短句、页码、标签。
3. `主张`：后续工作会依赖的主张。同样四列。
4. `覆盖判断`：每个后续条件标为覆盖、部分覆盖或不覆盖，并给页码。
5. `结论`：只能是 `可用`、`部分可用`、`不可用`、`材料不足停止` 之一。
6. `阻塞缺口`：一个句子。没有缺口就写“无”。
7. `未核查`：补充材料、图中读不出的数、你没有打开的页。

标签只有三种：`原文事实`、`推断`、`不能确定`。原文事实必须能在给出的页上找到原句。推断要写从哪一句推出来。不能确定就不要补数字。

## 步骤

1. 先数 PDF 页数，并列出目录里实际有的章节标题（摘要、方法、结果、讨论）。缺结果或讨论时，进入停止规则，不继续做覆盖判断。
2. 只从原文抄方法与条件。力场名字、温度、密度、是否断键，各自单独一行。
3. 把后续工作拆成可核对的条件（现象、化学、温度、密度、时间尺度）。
4. 对照。论文没做的现象，标不覆盖。论文做了结构、没做动力学，标部分覆盖，并写出不一致的页。
5. 结论取最严的一条：有任一关键条件不覆盖，就不是 `可用`。
6. 写完后检查：每个 `原文事实` 都有页码；没有页码的句子改成 `不能确定` 或删掉。

## 停止规则

出现下列任一情况，结论必须是 `材料不足停止`：

- 文本层不存在，或结果/讨论页不在文件中。
- 后续工作依赖的力场名称、温度或现象在现存页里找不到。

停止时只允许引用现存页。不要用摘要里的展望代替结果图。不要凭记忆补上常见数值。写明缺的是哪一段（例如“方法中的参考力场”或“讨论中的局限”）。

## 边界

- 非反应力场不能被说成描述了断键或爆轰，除非原文写出了反应。
- 极端温度或密度下的轨迹不能被说成实验室条件，除非原文给出了该条件。
- 粗粒化模型与全原子模型在熔融时间上不一致时，不能把动力学当成已验证。
- 本 Skill 不重跑模拟，不评价论文是否值得发表。
